Key Design Decisions

Status Window Changes

  • Background: #07080a → #111827 (matches frontend bg-base)
  • Border radius: 8px → 12px (matches frontend rounded-xl)
  • Add brand icon badge with indigo gradient
  • Service rows get individual card backgrounds (#1e293b)
  • Service icons: colored labels (API, UI, AI) instead of plain text
  • Port numbers in subtle code-style pill
  • Quit button: red gradient (destructive action) vs. subtle outline
  • Add uptime indicator

Tray Icon Changes

  • Color: Lime Green → Indigo gradient (#6366f1 → #a78bfa)
  • Warning state: Orange → Amber gradient (#f59e0b → #d97706)
  • Add glow shadow matching brand color
  • Outer ring: subtle brand-colored border
  • Tooltip: brand-colored header, cleaner spacing

Context Menu Changes

  • Background: #1e1e1e → #1e293b (matches frontend)
  • Font: Segoe UI → Inter, system-ui
  • Glyph icons → colored Unicode symbols per action group
  • Status row: green-tinted background with dot indicator
  • Exit item: red accent color for destructive action
  • Hover: #323232 → #263545 (slate hover)

Consistency Benefits

  • Single color palette across launcher and frontend
  • Identical border radius scale (6px, 8px, 12px)
  • Matching shadow hierarchy for depth cues
  • Unified typography (Inter family)
  • Launcher feels like part of the app, not a utility
  • Design tokens shared via CSS variables pattern
