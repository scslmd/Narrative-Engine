Theme Migration — CSS Variables

Theme Strategy — Before vs After
✗ Anti-Patterns (Before)
isDark ? 'bg-slate-900' : 'bg-white'
isDark ? 'text-slate-100' : 'text-slate-900'
bg-gray-50 dark:bg-slate-900
tabActiveBgMap[tab.key]  // 12 colors
✓ CSS Variables (After)
bg-[var(--bg-primary)]
text-[var(--text-primary)]
bg-[var(--bg-secondary)]
bg-[var(--color-primary)]  // stage-aware
