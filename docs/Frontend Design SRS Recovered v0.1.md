# Frontend Design SRS Recovered v0.1

The recovered frontend must eventually support:

- project selection by `project_name`
- pipeline job launch
- async backend progress monitoring
- role-model checker controls
- pass/fail and progress status for each role

Recovered UI priorities:

1. project-name-first identity
2. exact backend progress over fake timers
3. role-model checker as a supported user tool for model substitution
4. future writer-facing flows built on the same backend status primitives
