# Scrivener: Individual Report

## Overview
- **Type**: Desktop app (macOS, Windows, iOS)
- **Price**: $59.99 one-time (Mac/Windows); $23.99 iOS app
- **Best for**: Detailed planners with complex projects
- **URL**: https://www.literatureandlatte.com/scrivener/overview

## UI/UX Layout

### Main Interface
- Three-pane layout: Binder (left), Editor (center), Inspector (right)
- **Binder**: Tree-style sidebar for organizing files, folders, notes, research
- **Corkboard**: Digital index cards for scene-level planning
- **Editor**: Rich text editor with split-view capability
- **Inspector**: Side panel for metadata, character notes, custom fields

### Key Features
- **Binder**: Hierarchical file organization; drag-and-drop rearrangement
- **Corkboard**: Visual scene cards with synopsis summaries
- **Linguistic Focus Mode**: Highlight specific parts of speech (dialogue tags, adjectives)
- **Templates**: Free project templates for novels, screenplays, academic papers
- **Compile**: Multi-format export engine with customizable formatting rules

## Strengths
1. **Feature depth**: Comprehensive toolset for every writing stage
2. **Organization**: Binder + Corkboard is unmatched for complex projects
3. **One-time purchase**: No subscription; $59.99 covers all updates in version line
4. **Offline capable**: Full functionality without internet
5. **Template system**: Jumpstart projects with pre-built structures

## Weaknesses
1. **Steep learning curve**: Interface has 20+ features; newcomers overwhelmed
2. **UI feels dated**: macOS-native design; not modernized for current web standards
3. **No real-time collaboration**: Cannot co-edit with others simultaneously
4. **iOS app is separate purchase**: $23.99 extra for mobile access
5. **No AI integration**: No writing aids, brainstorming, or analysis tools

## UI/UX Observations
- **Strength**: Binder provides instant access to any project element; no digging through menus
- **Strength**: Corkboard gives visual overview of story structure at a glance
- **Weakness**: Three-pane layout wastes screen real estate on smaller displays
- **Weakness**: Inspector panel feels cluttered with too many metadata fields
- **Weakness**: Compile dialog has 10+ options; intimidating for first-time users
- **Weakness**: No dark mode in Windows version (macOS has it)

## Key UI/UX Deficiencies vs Narrative Engine
1. **No AI-assisted planning**: Corkboard requires manual card creation; Narrative Engine's P-100 generates outlines from story briefs with LLM analysis
2. **No automated canon management**: Worldbuilding scattered across Binder notes; Narrative Engine has structured world bible with typed entries and relationship tracking
3. **No consistency gates**: Linguistic Focus helps with style, not plot continuity; Narrative Engine's G-350 auto-detects contradictions against canon packet
4. **No story import**: Cannot paste existing story and extract structure; Narrative Engine has full import pipeline with LLM analysis
5. **No multi-chapter orchestration**: Chapters are independent files; Narrative Engine links chapters with prior context propagation and sequential dependency tracking
6. **No pattern extraction**: Cannot analyze existing text for archetypal patterns; Narrative Engine has dedicated pattern extraction service
