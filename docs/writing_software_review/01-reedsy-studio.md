# Reedsy Studio: Individual Report

## Overview
- **Type**: Web-based writing app
- **Price**: Free core; add-ons $4.99/mo (Craft), $7.99/mo (Outlining), $10.99/mo combined
- **Best for**: Self-publishers who want built-in formatting + planning in one tool
- **URL**: https://reedsy.com/studio

## UI/UX Layout

### Main Interface
- Clean, minimalist browser-based workspace
- Three distinct modes: Write, Plan, Format
- Sidebar navigation between manuscript sections
- No desktop app — entirely browser-based

### Writing Mode (`/studio/write-a-book`)
- Distraction-free editor with word count tracking
- Manuscript organization via chapter/section hierarchy
- Real-time autosave to cloud
- Dark mode available (Craft add-on)
- Beta reader collaboration sharing

### Planning Mode (`/studio/plan-a-book`)
- **Boards**: Visual kanban-style boards for organizing scenes, characters, research
- Drag-and-drop card organization
- Notes system for character profiles, worldbuilding elements
- Relationship mapping between story elements
- Unlimited Boards (Outlining add-on)

### Formatting Mode (`/studio/format-a-book`)
- Professional book formatting engine
- Print-ready PDF export with configurable trim sizes
- EPUB export for ebooks
- Front/back matter templates (copyright page, TOC, etc.)
- Live preview of formatted output

## Strengths
1. **All-in-one workflow**: Plan → Write → Format in single environment
2. **Free tier is generous**: Core writing + basic formatting available without payment
3. **Clean UI**: No feature bloat; intuitive navigation between modes
4. **Professional export**: Print-ready PDF and EPUB without separate formatting tool
5. **Boards system**: Visual planning comparable to Scrivener's Corkboard but more modern

## Weaknesses
1. **No offline access**: Requires internet connection at all times
2. **No mobile app**: Desktop browser only
3. **Limited collaboration**: Sharing exists but lacks real-time co-editing
4. **Add-on fragmentation**: Core features split across free/paid tiers can be confusing
5. **No AI assistance**: No writing aids, brainstorming, or analysis tools

## UI/UX Observations
- **Strength**: Mode switching is seamless; no context switching between apps
- **Strength**: Visual hierarchy is clear; writer always knows where they are
- **Weakness**: Boards interface feels slightly cramped on smaller screens
- **Weakness**: Formatting mode requires learning trim size concepts upfront
- **Weakness**: No keyboard shortcuts visible in UI; discovery relies on help docs

## Comparison to Narrative Engine Pipeline

| Aspect | Reedsy Studio | Narrative Engine |
|--------|---------------|-----------------|
| Planning | Manual Boards (drag-and-drop cards) | AI-assisted P-100 Architect phase generates structured outlines |
| Writing | Distraction-free editor with word goals | AI-assisted P-300 Drafter with canon context injection |
| Formatting | Built-in print/ebook export | Manuscript compilation via P-400 Compiler |
| Worldbuilding | Notes system (manual) | Dedicated world bible with structured entries |
| Characters | Character notes in Boards | Full character profiles with relationships, arcs, continuity tracking |
| AI Integration | None | Core feature: LLM-driven generation, analysis, consistency gates |
| Canon Management | Manual notes only | Automated canon packet builder with budget-aware truncation |
| Consistency | Writer must self-check | G-350 gate system auto-checks contradictions |
| Pricing | Free core, $10.99/mo max | Self-hosted (free), local LLM inference |

## Key UI/UX Deficiencies vs Narrative Engine
1. **No AI-assisted planning**: Writer must manually create all structure; Narrative Engine's P-100 generates outlines from story briefs
2. **No canon automation**: Worldbuilding and characters are manual notes; Narrative Engine has structured world bible, character profiles, relationship graphs
3. **No consistency checking**: No automated gate system to catch contradictions; relies entirely on writer vigilance
4. **No multi-chapter orchestration**: Each chapter is independent; Narrative Engine's batch mode links chapters with prior context propagation
5. **No import workflow**: Cannot paste existing story and auto-extract structure; Narrative Engine has full story import with LLM analysis
