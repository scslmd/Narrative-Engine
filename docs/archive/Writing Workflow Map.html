Non-Linear Navigation

Mid-Draft Ideation

  • Drafting → discover missing concept
  • Open Ideas panel → capture idea
  • Promote to Characters / World Bible
  • Return to drafting with new context

Just-in-Time Research

  • Drafting → encounter detail gap
  • Open Research panel → add reference
  • Fill in factual details
  • Return to drafting with verified info

Canon-Tight Loop

  • Revision → Checker finds contradiction
  • Inspect → trace root cause
  • Annotate canon field for enforcement
  • Re-run generation → verify fix

Generate → Change → Regenerate

1

Generate

Run generation for Ch 7 (The Conversation). AURA-7 speaks in full sentences.

2

Discover Issue

Conversation reads like two humans talking. AURA-7 should sound like a degraded AI.

3

Change Canon

Characters → AURA-7 → Voice Notes: "Speech is fragmented. Random pauses. Occasional garbled words."

4

Regenerate

Re-run Ch 7 with Block continuity strictness. AURA-7 now speaks: "The sea... rises. 40 meters. You are... the last light."

5

Verify & Continue

Read revised chapter. Pattern carries forward to Ch 8. Move to Revision stage.
